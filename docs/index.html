SIMPLE

[SIM]ulating for peo[PLE]

An open-source building performance simulation tool that simulates heat, light and air together, so we can study how buildings perform for the people who live in them.

Get started Validation reports Source code

What is SIMPLE?

People do not separate the thermal, daylight and acoustic performance of a room: they just feel it. SIMPLE was designed so that all those domains share a single simulation state, and so that the behaviour of people, such as opening a window or switching on a heater, can be part of the simulation as it runs.

☀️

Holistic

Heat transfer, solar and long-wave radiation, daylight, infiltration and ventilation, solved together at every timestep rather than in separate runs.

🧑‍🤝‍🧑

Made for people

Control buildings with Rhai scripts that read and change the state, from window operation to model predictive control.

🌍

Runs everywhere

Written in Rust: a command-line tool for Windows, Linux and Mac, a library, and WebAssembly (try the browser demo).

🔍

Transparent

Open source (MIT), and validated against EnergyPlus, Radiance and analytic solutions. Every release regenerates the reports below.

Getting started

  1. Download a binary for your platform from the releases page, or build it with cargo build --release.
  2. Describe your building in a .spl file (see the guide and the input reference).
  3. Run it with an EPW weather file.
# Simulate a year, 4 timesteps per hour
simple -i model.spl \
       -w wellington.epw \
       -n 4 \
       -o results.csv

# Add a control script
simple -i model.spl -w wellington.epw \
       -c control.rhai -o results.csv
